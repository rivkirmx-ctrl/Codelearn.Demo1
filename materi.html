Struktur Dasar Dokumen HTML

Estimasi waktu: 10 Menit • Tingkat: Pemula

1. Pengenalan Konsep

Setiap dokumen HTML memiliki kerangka standar yang wajib ditulis agar browser dapat membaca dan menampilkan isi halaman web dengan benar.

2. Kenapa Ini Penting?

Di dunia kerja dan proyek nyata, melewatkan tag utama seperti dapat menyebabkan browser masuk ke dalam Quirks Mode, yang mengakibatkan tampilan CSS menjadi rusak atau tidak konsisten antar browser.

3. Contoh Kode

<!DOCTYPE html> <html lang="id"> <head> <meta charset="UTF-8"> <title>Halaman Pertama Saya</title> </head> <body> <h1>Hello CodeLearn!</h1> <p>Saya siswa SMK siap menjadi Web Developer.</p> </body> </html>

4. Bedah Kode secara Detail

  • <!DOCTYPE html>: Deklarasi standar untuk memberi tahu browser bahwa file ini menggunakan versi HTML5.
  • <html>: Tag pembungkus utama seluruh elemen pada dokumen HTML.
  • <head>: Berisi informasi metadata (seperti judul browser dan pengaturan karakter) yang tidak terlihat langsung di halaman utama.
  • <title>: Menentukan judul yang muncul pada tab browser Anda.
  • <body>: Tempat menaruh seluruh konten visual seperti teks, gambar, dan tombol.

5. Kesalahan Umum Pemula

⚠️ Perhatian: Banyak pemula lupa menutup tag (misalnya menulis <p>isi teks tanpa </p>) atau menulis tag di luar elemen <body>. Pastikan selalu memeriksa pasangan tag pembuka dan penutup.

6. Latihan Mandiri

Coba buka halaman Playground, lalu ganti teks di dalam tag <h1> dengan nama lengkap dan sekolah SMK Anda.
